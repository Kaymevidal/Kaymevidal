> Desenvolvedor Backend focado em **Java + Spring Boot** e **Python**, buscando minha primeira posição formal como **Desenvolvedor Backend Júnior ou Estagiário**, em regime **100% remoto**, com disponibilidade imediata.

Já apliquei conhecimento técnico em cenários reais, entregando valor de negócio tanto para clientes freelancer quanto em ambiente de produção institucional:

- 💼 **Freelancer Backend (7+ meses)** — Desenvolvimento e manutenção de **APIs REST** funcionais em **Java 17/21 + Spring Boot 3.x** para múltiplos clientes, cobrindo desde modelagem de dados até deploy.
- 🏛️ **Suporte Técnico — Prefeitura Municipal (4 meses)** — Atuação direta em **ambiente de produção real** e infraestrutura de TI de um órgão público, desenvolvendo senso crítico para estabilidade, segurança e continuidade de serviços.
- 🧠 **Boas práticas de engenharia** — Aplicação de **Arquitetura Limpa**, princípios de **Microsserviços** e cobertura via **Testes Unitários e de Integração**.
- 🤖 **Inovação** — Experimentação com **Ollama** para rodar LLMs localmente, integrando IA a soluções backend.
